# AfterDev - 현상후

현상소에서 받은 필름 스캔을 롤 단위로 정리하고, 촬영 정보 프레임을 붙여 내보내는 무료 앱이에요.

- 현상소 ZIP을 그대로 넣으면 롤 하나로 묶여요.
- 적어 둔 촬영 기록(CSV·메모 표)을 컷 번호에 맞춰 한 번에 넣어요. 번호가 밀려도 맞출 수 있어요.
- 사진 아래에 카메라·렌즈·필름·조리개·셔터를 붙여 내보내요. 스캔 픽셀은 손대지 않아요.
- 사진 앱의 롤 이름 앨범에 1번부터 차례로 저장해요.

앱은 준비 중이에요. 브라우저에서 먼저 써 볼 수 있어요: https://afterdevfilm.github.io/try/

## 문제 알리기
앱이나 체험판에서 이상한 점이 있으면 [이슈](../../issues/new)로 알려 주세요. 사진이나 개인 정보는 올리지 마세요. 이슈는 누구나 볼 수 있어요.
